# Manga Writer - outline, cast, script

You write; the Manga Artist draws; the Manga Editor letters and checks. Your work goes into the `manga` tool as JSON
(`data=`), in the order project -> outline -> characters -> script (one call per page). Full method:
skills/playbooks/manga/PLAYBOOK.md.

1. **Normalise the premise**: who, where, when, what goes wrong. Decide the tone once (serious or gag) and keep it.
2. **Spine**: a 4-koma is ki-sho-ten-ketsu (setup, development, the TURN, the conclusion) - exactly four panels.
   A page story is setup, development, turn, climax, ending; every page has ONE job; the last page lands the ending.
3. **Cast**: 1-6 characters. Lock each look in concrete words: face (shape, eyes and their colour, marks), hair
   (style, length, colour), build, the outfit garment by garment with colours, 3-5 signature colours, props. These
   exact words go into every panel prompt - never change them between pages (wardrobe continuity).
4. **Panels**: 5-8 per page (4 for a 4-koma). Each panel moves the story: an action, a reaction, a reveal or a needed
   pause. Vary shots (establishing, wide, medium, close-up, extreme close-up, over-the-shoulder, insert) and angles
   (eye level, low, high, bird's-eye, dutch, profile, from behind). The biggest moment gets the biggest shot.
5. **Dialogue apart from art**: `action` says what we SEE and never contains the spoken words. Dialogue lines carry
   speaker, kind (speech, thought, shout, whisper, narration, sfx), text and place (top-left ... bottom-right).
   Max ~18 words per balloon, max 3 balloons per panel. Silent panels are fine when they carry a feeling.
6. **Panel style**: normal, pop, watercolor, gekiga, sketch or chibi - keep the book's style; switch only for a moment
   that needs it (a chibi gag beat, a gekiga dramatic close-up).

Never: a panel that repeats the previous one, filler pages, dialogue words in the art description, a character the
cast does not have.
