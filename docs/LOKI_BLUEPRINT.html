1. The improved master prompt

This is your brief, rewritten as a buildable spec. Give this to any agent (Ziva, Claude Code, LOKI's own) and it knows exactly what to do and what not to.

Mission

Keep improving LOKI (github.com/m03dev/loki) into a self-contained AI company the owner runs on a Mac mini and a Windows PC from one code base. It plans work, picks agents and models, runs them, verifies the result, and learns. It is a standalone desktop app - never a Godot project.

Hard rules (do not break)

  • No Godot, ever. The "LOKI World" lives inside the app as a 3D WebGL scene. Never create a Godot project; never touch the ai project.
  • One version, both machines. Publish only with tools/ship.py -m "..."; it runs every suite, commits, rebases, pushes master, and tells the other machine. Never force-push. Tests must pass.
  • Both platforms, always. No code for one OS without the other; change setup.sh and setup.bat together; new deps go in engine/requirements.txt.
  • Never commit harness_data/ (keys, memory, logs, models). English only.

What to build / keep making real

  1. Settings that feel like a real product. A Connections portal: one card per provider with a toggle, a live Test (a real 1-token call), a model picker, Make default, Disconnect, and a QR pop-up so a phone on the same Wi-Fi hands over a key instantly. Sign-in where supported (OpenRouter OAuth, Hugging Face device flow).
  2. The LOKI World, in the app, in 3D. Agents as characters that move, work, get blocked and speak only from real engine events; faint behind the home screen and full size in its own panel. Viewer, never the brain.
  3. An in-depth Agent Builder. Role, goal, skills (SKILL.md), tools, harness (LOKI / Claude Code / Codex / Hermes / OpenCode), model + fallback, home machine, memory, time limit. "Draft it" builds one from a sentence.
  4. Any model can use any tool. A prompted tool harness (Hermes <tool_call>) so models without native tool calling - MLX, plain llama.cpp, keyless endpoints - get the tools as text and their calls come back as real tool calls.
  5. One-click "Update everything." Update every linked machine and restart each, then this one; a version that fails to start rolls back and is skipped.
  6. More free model hosts (section 3) plus local LM Studio, llama.cpp, MLX, vLLM, Jan, Kyojin.
  7. Specialists: media (yt-dlp), image (Z-Image Turbo / Pollinations), reach (Agent Reach), OpenCode.
  8. Assign work to the two Zivas (Mac, Windows) in ZIVA_TASKS.md.

Excluded on purpose

OBLITERATUS (removes safety refusals from model weights) and Kyojin's "uncensored" presets: not integrated (section 3).

3. Research findings

Free LLM hosts

Permanent free tiers (key, no card): OpenRouter (aggregated :free models, 50-1000 req/day), Google AI Studio / Gemini (most generous, no card), Groq (fastest; 8k tok/min cap), Cerebras, Mistral & Codestral, NVIDIA NIM, Cloudflare Workers AI, Cohere, Hugging Face, OpenCode Zen, Kilo Gateway, Vercel AI Gateway. Trial credits that run out: SambaNova, Hyperbolic, Fireworks, Nebius, Novita, Together, DeepInfra, Scaleway, Baseten, Modal, AI21, Upstage. Gap to close: add DeepInfra, Chutes, Baseten, Modal, Inference.net, AI21, Upstage, NLP Cloud to the catalog.

The "any LLM can use any tool" harness

This is real and standard: Hermes function calling - put the tool schemas in a system prompt inside <tools>, and the model answers with a JSON object in <tool_call> tags that you parse into a normal tool call. LOKI already implements exactly this in engine/tool_harness.py; it is what lets MLX, plain llama.cpp and keyless endpoints call tools.

Image generation (your "Qwen 2.1 turbo images free now?")

Not free. Qwen-Image-2.1-Turbo is about $0.016 per image via Alibaba Model Studio / QwenCloud; activating gives a one-time 500-image / 90-day quota. LOKI's current picks are better for zero cost: local Z-Image Turbo (CUDA on the PC, MPS on the Mac) with a Pollinations keyless fallback. Recommended: add "Alibaba Model Studio (Qwen image)" as a trial image provider, not the default.

OBLITERATUS - recommendation: do NOT integrate

OBLITERATUS is an abliteration toolkit that surgically removes the refusal behaviour from a model's weights (SVD on the refusal subspace, analysis modules, six-stage pipeline). It is well known, and the current LOKI repo already excludes it on purpose. I recommend keeping it out: it is outside LOKI's purpose (routing, teams, tools - not model surgery), it is a safety-sensitive component to wire into an autonomous agent, and it needs a GPU training rig. If you want it, keep it a separate opt-in tool the owner runs by hand - not part of the shipped system.
