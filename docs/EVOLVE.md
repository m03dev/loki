# EVOLVE - LOKI grows its own personal-agent core

LOKI builds its own "OpenHuman" inside itself, one step at a time, by itself (engine/evolve.py).
When LOKI is idle, the autopilot takes the first open line below (after the owner's own ideas
from Settings > Lab) and hands it to `improve_loki`: a background LOKI agent changes LOKI's code
in its own git worktree, runs every test suite, and ships only when all of them pass. That
agent ticks the line (`- [ ]` -> `- [x]`) in the same commit, so a finished step is finished on
every machine. A step that did not ship is tried again after 3 days, with what went wrong in
its prompt. Settings > Lab shows all of it; LOKI_EVOLVE (Settings > General) turns it on or off
(auto = only on the Windows PC, which is on 24/7).

Rules for every step: never remove a feature to make room; keep the window fast (no heavy
dependency without need); macOS and Windows; a test for what is built; the world keeps its
pixel cel-shaded look.

Since session 26 LOKI also carries code ported from OpenHuman (memory, sub-agents), OpenHands
(condenser, stuck detection, file editing, task tracker, command risk) and Scrapling (native web
reading) - see docs/THIRD_PARTY.md. LOKI is AGPL-3.0 since 2026-10-17 (public repository): take code only under licences compatible with it (MIT, BSD, Apache-2.0, GPL-3.0, AGPL-3.0, ...) - never proprietary or non-commercial code.

- [ ] E15 Ground texture fix - the owner: "the ground texture ... clip mapping or something needs rework". The island ground in LOKI World flickers/clips: paths, pools, plaza, flower patches, blob shadows and decals fight the grass (z-fighting), and the ground texture swims/shimmers when the camera moves. Fix it in the Babylon renderer (app/ui/world_babylon.js - the static baked ground, blob shadows SHADOW_VS/FS, decals) AND the classic renderer (app/ui/world.js): give every ground layer its own small height step and/or zOffset (material.zOffset / depth bias) in a fixed order (grass < dirt/paths < plaza < shadows < decals), snap texture/dither to world space so it does not swim, and check near/far planes so depth precision is enough. Keep the pixel cel-shaded look (cel bands, ink lines, pixel grid, posterize). Test: a headless-Chromium screenshot test at 3 camera angles (tests/ with fake /world data) plus a pixel-stability check (two frames 1 px of camera move apart differ little on the ground).
