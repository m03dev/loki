# LOKI integration research: marketing, game-making, 3D, pixel art, platform

Date: 2026-10-25. Scope: web research only, no code was changed.

**Hardware assumed:** Mac mini M4 with 16 GB unified memory, and a Windows PC with an RTX 3070 Ti (8 GB VRAM).

**LOKI constraints:** LOKI is licensed AGPL-3.0. Code under GPL, AGPL, MIT, Apache-2.0 or BSD can be copied into it. Code under "community", research-only or source-available licenses cannot be copied; LOKI can only call it as an external tool or service, and those cases are flagged below.

**How the facts were checked:** The GitHub API and `gh` were blocked in this session, so I verified projects by fetching their GitHub README pages and third-party pages.
- GitHub pages often did not render the last-commit date. Where the date is unknown, the report says "date not visible".
- Star counts are as rendered on the page on the day of fetching.
- Effort ratings: S is under 1 day, M is 1–3 days, L is a week or more.

## 1. Marketing and promotion agents for an indie game

### 1.1 Pick: Postiz (self-hosted scheduler with API, MCP and CLI)
- **What it is:** an open-source social scheduler with a calendar, AI post and video helpers, analytics, a public API, an MCP server, an n8n node and a Node SDK (`@postiz/node`).
- **Platforms:** the MCP page lists 30: X, LinkedIn, Instagram, Facebook, Threads, Reddit, YouTube, TikTok, Pinterest, Bluesky, Discord, Slack, Telegram, Mastodon, Twitch, Kick, Lemmy, Nostr, WordPress, Medium, Dev.to, Hashnode and others.
- **Repos:**
  - https://github.com/gitroomhq/postiz-app (the app, AGPL-3.0).
  - https://github.com/gitroomhq/postiz-agent (the agent CLI, AGPL-3.0, about 410 stars). Install with `npm i -g postiz`. Commands include `posts:create`, `integrations:list`, `analytics:post` and `upload`. Point it at a self-hosted instance with `POSTIZ_API_URL` and `POSTIZ_API_KEY`.
- **Why it's the pick:**
  - It uses the same license as LOKI.
  - The self-hosted edition gates no features: API, MCP and all platforms are included (per Blotato's comparison, a competitor, dated Sept 2026).
  - It is the only open-source option that covers Bluesky, Reddit, TikTok, YouTube and Discord together.
- **Hardware fit:** a Docker stack (Postgres and Redis). It can run on the Mac mini or the PC; no GPU needed.
- **How LOKI would integrate:**
  - Add a "Promote" tab that shells out to the `postiz` CLI, or talks to the self-hosted REST API.
  - Agent harnesses (Claude Code, OpenCode) get the CLI skill (`npx skills add gitroomhq/postiz-agent`) or the MCP endpoint.
  - The hosted MCP is at `https://mcp.postiz.com/mcp-oauth-dynamic`. I could not confirm whether the MCP server is part of the self-hosted build.
- **Effort:** M (Docker setup, one OAuth app per platform, and a UI tab).
- **Sources:** [postiz.com/mcp](https://postiz.com/mcp), [postiz-agent](https://github.com/gitroomhq/postiz-agent), [Blotato: Mixpost vs Postiz](https://www.blotato.com/blog/mixpost-vs-postiz), [Postiz v2 release post](https://scribe.disroot.org/post/3874477).

### 1.2 Alternative not recommended: Mixpost
- **What it is:** a Laravel/PHP social scheduler.
- **Why not:** Mixpost Lite is MIT but covers only Facebook Pages, X and Mastodon, and has no API. The API, Instagram support and a 26-tool MCP server require Pro ($299 one-time) or Enterprise.
- **Source:** [Blotato comparison](https://www.blotato.com/blog/mixpost-vs-postiz).

### 1.3 Pick: OpenShorts (turn long gameplay video into Shorts, Reels and TikToks)
- **Repo:** https://github.com/mutonby/openshorts
- **License:** MIT for the core app. The `cloud/` folder is under a separate commercial license, so do not copy it.
- **Maturity:** about 5.3k stars and 429 commits.
- **What it does:**
  - Picks highlight moments with an LLM, reframes to 9:16 with face tracking (MediaPipe and YOLOv8), and burns in subtitles with faster-whisper.
  - Writes hooks, YouTube titles, thumbnails and chapters.
  - Has an MCP server (`/mcp` and `mcp_stdio.py`) with tools such as `process_video`, `add_subtitles` and `publish_clip`, a REST API, a CLI and an agent skill.
- **Local models:** the LLM is set with `LLM_BASE_URL`, so it works with Ollama. The README says 7–8B models give reliable JSON, which makes qwen3.5 9B a good fit.
- **Limits:**
  - Some layout and content detection still needs a Gemini key; without one it falls back to a plain face-tracking crop.
  - Posting goes through the third-party Upload-Post service (10 uploads a month on the free tier). Postiz can do the posting instead.
- **Hardware fit:** the README says 8 GB VRAM is enough for whisper large-v3-turbo plus the detectors, so the RTX 3070 Ti fits. CPU-only works, about 5–8 minutes per 8-minute video.
- **How LOKI would integrate:** a Docker service on the PC; LOKI calls the MCP or REST API. Gameplay clips come from Godot Movie Maker (1.5).
- **Effort:** M.
- **Note on gameplay footage:** face tracking matters less for gameplay with no facecam. Expect to tune the moment-picking prompt.
- **Alternative:** [Clips Kitty / clips-studio](https://github.com/ColinGPT9/clips-studio).
  - AGPL-3.0-or-later; plugin SDK is MIT. About 133 stars.
  - Uses Ollama, faster-whisper and an MCP server.
  - Posts to YouTube through the official Data API.
  - The desktop app is Windows-only.

- **[GarrettPetersen/indie-game-marketing-skills](https://github.com/GarrettPetersen/indie-game-marketing-skills)**

  - Source: [ecosyste.ms entry](https://awesome.ecosyste.ms/projects/github.com%2Fpixelnest%2Fpresskit.html).

### 1.5 Trailer and video building blocks (LOKI-native)
- **Godot Movie Maker mode** (built into Godot 4, run with `--write-movie out.avi`) renders deterministic, frame-perfect gameplay captures. The Engine tab can script a "record trailer take" button.
  - Effort: S.
  - This is from my own knowledge of Godot; I did not fetch it this session.
- **Editing:** use ffmpeg plus a Python editor such as MoviePy (MIT) for title cards and cuts.
  - **Avoid Remotion:** it is source-available, not open source, and free only for organizations of 3 people or fewer. Its code cannot be copied into AGPL LOKI. [License FAQ](https://www.remotion.dev/docs/license/faq).
- **AI b-roll and video:**
  - **LTX-2.3** (Lightricks, open weights under the LTX-2 Community License): the 22B dev checkpoint is heavy; distilled and upscaler variants exist for consumer GPUs ([overview](https://invideo.io/blog/ltx-ai-video-generator/)). I could not confirm it runs on 8 GB. Treat it as a cloud or Space route for now.
  - Wan 2.2 5B through ComfyUI is the usual 8 GB local option. Not re-verified this session.

### 1.6 Platform rules and API limits (be honest with the owner)

| Platform | Programmatic posting status (2026) | Risk |
|---|---|---|
| X | No free tier for new developers. Pay-per-use at about $0.015 per post and $0.20 per post with a link (raised April 2026). [postproxy](https://www.postproxy.dev/blog/x-api-pricing-2026/) | Low cost at indie volume. Labelled automated accounts are allowed under X's automation rules. |
| Reddit | The Responsible Builder Policy (Nov 2025) requires approval for new OAuth apps. Unauthenticated `.json` requests return 403 since May 2026. [KeyApi summary](https://www.keyapi.ai/blog/reddit-data-api-overhaul-major-changes-and-migration-guide/) (third-party; verify on r/redditdev) | **High.** Subreddits ban self-promotion bots, and automated promo posting gets accounts banned. Use agents to draft Reddit posts; the human posts them. |
| TikTok | The Content Posting API forces `SELF_ONLY` (private) until the app passes TikTok's audit. Unaudited apps: up to 5 users in 24 hours, private accounts only, plus HTTPS-verified domains. [Postiz TikTok docs](https://docs.postiz.com/providers/tiktok.md) | Medium. Needs the audit, or use Postiz cloud's already-audited app. |
| YouTube | `videos.insert` now draws from a separate "Video Uploads" quota (about 100 uploads a day). The docs say unverified projects are no longer restricted to private. [Google docs](https://developers.google.com/youtube/v3/docs/videos/insert) | Low. |
| Bluesky | Open AT Protocol with official bot starter templates. | Low. Label the bot account. |
| Discord | Webhooks or a bot on your own server. | Low. |
| Instagram | Requires a Business or Creator account linked to a Facebook Page and Meta app review. Not re-verified this session. | Medium. |
| Steam | **No API to post events or devlogs.** ISteamNews is read-only ([docs](https://partner.steamgames.com/doc/webapi/ISteamNews)). A Steamworks **wishlist data API** launched March 2026; it uses the same permissions as the financial/sales API ([gamedev.net](https://gamedev.net/news/2104-new-steamworks-wishlist-data-api/), [wishlist reporting](https://partner.steamgames.com/doc/marketing/wishlist/reporting)). | Agent drafts the Steam event text; the human pastes it. LOKI can chart wishlists daily from the API. |

**Browser-automation posting** (for example browser-use or Playwright driving a logged-in browser):
- It technically works for platforms without APIs, but it violates most platforms' terms of service when used to automate accounts. It is the fastest route to a shadowban or a ban on the game's official accounts.
- Recommendation: use official APIs through Postiz, and keep a human approval step before every publish.
- Also note: the owner has banned screen control on their own computer, so any browser automation must be headless and API-driven (1.6 and 5.3).

## 2. Agents that make games (Godot-first)

### 2.1 Pick: godot-ai (MCP server and editor plugin)
- **Repo:** https://github.com/hi-godot/godot-ai
- **License:** MIT. About 3.1k stars and 1,122 commits.
- **What it does:**
  - 46 tools covering 120+ operations: scenes, nodes, scripts (GDScript is parse-validated and hot-reloaded), signals, UI, materials, animation, particles and cameras.
  - Editor and running-game screenshots, plus input injection (keys, mouse, gamepad).
- **Requirements:** Godot **4.7+**.
- **How it connects:** the MCP client runs `godot-ai attach` over stdio. That process talks to a Python server over HTTP on port 8000, which talks to the editor plugin over a loopback WebSocket on port 9500.
- **Clients:** officially lists Claude Code, Codex, **DeepSeek Harness**, Cursor and others; those match LOKI's harnesses.
- **Why it's the pick:** it is the strongest free option, it lets the agent play-test the game it built, and it is MIT so it can be copied.
- **Integration:** godot-ai covers open-source and local models.
- **Hardware fit:** Mac and PC. No GPU needed.
- **Effort:** S–M (bundle the plugin into the Engine tab and register the MCP server with each harness).
- **Sources:** [repo](https://github.com/hi-godot/godot-ai), [dev.to 2026 roundup](https://dev.to/orellanaed/the-best-godot-mcp-server-in-2026-depends-on-what-you-want-the-agent-to-touch-5aji). The roundup's author makes Flockbay, a competitor.
- **Alternatives:**
  - [Coding-Solo/godot-mcp](https://github.com/Coding-Solo/godot-mcp): MIT, starts with one `npx` command, launches and runs projects and reads debug output; no screenshots.
  - satelliteoflove/godot-mcp: MIT, 21 tools, can pause and step game time.
  - **Avoid:** ee0pdt and bradypp godot-mcp (stale since 2025).

### 2.2 Pick: Godogen (autonomous "describe a game, get a project")
- **Repo:** https://github.com/htdt/godogen (the original; 6ogo/godogen and Ralf12358/godogen are forks).
- **License:** MIT. About 7.2k stars. Featured on HN and GIGAZINE in March 2026.
- **What it does:**
  - Renders a game repo for a chosen engine and agent, for example `./publish.sh --engine godot --agent claude`. Engines: Godot 4 (GDScript or C#), Bevy, Babylon.js, three.js. Agents: Claude Code or Codex.
  - The agent generates assets, runs the engine and checks the running game. It produces a recording at the end.
- **Assets:**
  - Local `godogen_assets` (needs an NVIDIA GPU).
  - Or paid APIs: Gemini images, TTS and Lyria music; Grok images and animated sprites; Tripo3D models.
- **OS:** tested on Ubuntu, Debian and macOS. Windows is not mentioned, so use WSL2 on the PC.
- **How LOKI would integrate:**
  - A "New game from prompt" wizard in the Engine tab that runs `publish.sh`.
  - Then hand off to the chosen harness.
  - Swap the asset step to LOKI's own image, 3D and pixel pipelines.
- **Effort:** M.
- **Sources:** [repo](https://github.com/htdt/godogen), [HN thread](https://news.ycombinator.com/item?id=47400868).

### 2.3 Supporting picks
- **[pamirtuna/gamestudio-subagents](https://github.com/pamirtuna/gamestudio-subagents)**
  - MIT, about 270 stars.
  - 12 Claude Code sub-agent role prompts (orchestrator, producer, market analyst, game designers, mechanics, QA and others). Supports Godot, Unity and Unreal.

  - Effort: S.

  - Effort: reference only.
- **Music: [ACE-Step 1.5](https://github.com/ACE-Step/ACE-Step-1.5)**
  - MIT (changed from Apache), released 31 Jan 2026.

  - Effort: S–M. [Article](https://lilting.ch/en/articles/ace-step-1-5-music-generation).
- **Sound effects: Stable Audio 3.0 Small SFX**
  - 459M parameters, open weights, released May 2026.
  - Stability Community License: free under $1M annual revenue. Call it as a model; do not vendor its code into AGPL LOKI.
  - Designed for laptops, so it should fit both machines.
  - Effort: S–M. [The Decoder](https://the-decoder.com/stability-ai-launches-stable-audio-3-0-with-up-to-six-minute-tracks-and-open-weights/).

- [shivampkumar/trellis-mac](https://github.com/shivampkumar/trellis-mac) ports TRELLIS.2 to MPS, but peak memory is about 18 GB and the reviewer says 24 GB is the real minimum.

- **Effort:** S–M.

## 4. AI pixel art

### 4.1 Generation models and LoRAs
- **Z-Image Turbo plus a pixel LoRA** (LOKI already runs Z-Image locally)
  - Text-to-image works. Image-to-image conversion does **not** work well.
  - Needs `Comfyui-ZiT-Lora-loader` with `auto_convert_qkv`; the standard loader has no effect.
  - LoRAs: Pixel Art Style LoRA, PixelArt Perfect, PixelSIN (Civitai). [Test write-up](https://lilting.ch/en/articles/z-image-pixel-art-conversion).
- **Qwen-Image-2512 Pixel-Art LoRA:** [HF link](https://huggingface.co/prithivMLmods/Qwen-Image-2512-Pixel-Art-LoRA). Fits LOKI's Qwen-Image path. Licenses vary per LoRA; check each card.
- **FLUX.1-dev Modern Pixel Art LoRA:** [HF link](https://huggingface.co/UmeAiRT/FLUX.1-dev-LoRA-Modern_Pixel_art). FLUX.1-dev uses a non-commercial license for the weights.
- **SDXL / Illustrious plus nerijs pixel-art-xl:** still the most reliable **image-to-image** pixelization route (denoise 0.6, about 6.5 GB VRAM, per the Z-Image test above). Fits the 3070 Ti.
- **FLUX.2 [klein] 4B** (Apache-2.0, Jan 2026): one model for generation **and** editing, from about 13 GB VRAM, with FP8 and NVFP4 builds. A candidate for pose and variation edits of a sprite; 8 GB is likely too tight without quantization. [GIGAZINE](https://www.gigazine.net/gsc_news/en/20260116-flux2-klein).
- **Retro Diffusion:** a commercial API and Aseprite extension, not open weights. Usable through [svntax/ComfyUI-RetroDiffusion-API-Node](https://github.com/svntax/ComfyUI-RetroDiffusion-API-Node) if the owner wants to pay.
- **PixelLab:** a paid API with an official MCP server ([pixellab-mcp](https://github.com/pixellab-code/pixellab-mcp)). It does 4- or 8-direction characters, walk, run and idle animation, and **Wang tilesets** and isometric tiles. It is the strongest turnkey tileset and animation option; it costs money and is closed source. [mcpservers](https://mcpservers.org/servers/pixellab-code/pixellab-mcp).

### 4.2 Post-processing (the step that makes it "real" pixel art)
- **PixelOE** ([KohakuBlueleaf/PixelOE](https://github.com/KohakuBlueleaf/PixelOE))
  - MIT, about 532 stars, last commit about 3 weeks ago.
  - Install with `pip install pixeloe`. Classic image processing with contrast-aware outline expansion, then downscale. CPU works; a PyTorch GPU path is optional.
  - Also available as a ComfyUI node in ComfyUI_essentials ("PixelOE Pixelize").
  - **Pick:** make it the final step of every pixel workflow. Runs on the Mac too.
  - Effort: S. [sourcepulse](https://www.sourcepulse.org/projects/2338779).
- **ComfyUI-Unfake-Pixels** (edge-aware auto-scale) and **PixelArt-Detector** nodes for palette, grid snapping and fixing "fake" pixel art. Licenses not verified.

### 4.3 Sprite sheets, animation and tilesets
- **agent-sprite-forge** ([repo](https://github.com/0x0funky/agent-sprite-forge))
  - MIT, about 4.5k stars, v0.4, validated 2026-10-06.
  - An agent skill for Claude Code, Codex or Grok.
  - Workflow: master still, then an image-to-video clip per action, then Python keys, loops, retimes and packs the frames.
  - Exports **Godot 4 SpriteFrames `.tres`** and AnimatedSprite2D/3D, TileMapLayer maps, Tiled, LDtk and Aseprite.
  - Backends are API keys (OpenAI, Gemini, xAI, fal, BytePlus) or the signed-in Codex/Grok CLIs. LOKI could add a backend that routes to its local Z-Image or ComfyUI.
  - Caveat: the README says the Godot and Aseprite exports have not yet been opened in the editors.
  - **Pick for the sprite-sheet pipeline.** Effort: M.
- **PerfectPixel Studio** ([repo](https://github.com/gykim80/perfectpixel-studio))
  - MIT, about 588 stars.
  - 8-direction sets with 100+ motion presets, a self-correcting loop and shared-palette pixelization. Exports Aseprite JSON.
  - Uses cloud APIs only (Gemini 3 Pro Image and others).
  - Worth copying its direction-mirroring and palette-lock logic. Effort: M.
- **Aseprite MCP: [willibrandon/pixel-mcp](https://github.com/willibrandon/pixel-mcp)**
  - MIT, Go, v0.5.0 (Oct 2025). Needs Aseprite 1.3+.
  - 48 tools, including draw, dither, palette, shading, frames and tags, `export_spritesheet` and `downsample_image`.
  - Lets agents clean up and animate in Aseprite. Mac and PC.
  - Effort: S.

## 5. Broader LOKI improvements (strong picks only)

### 5.1 Agent memory and self-cleanup
- **Hindsight** (Vectorize)
  - MIT. One Docker container with embedded Postgres; self-hosted has feature parity with cloud.
  - Claims top published retrieval scores; these are vendor claims. [Vectorize blog (biased)](https://hindsight.vectorize.io/blog/2026/08/11/open-source-agent-memory-systems).
- **Mem0**
  - Apache-2.0, largest community.
  - Extracts facts from turns instead of storing transcripts, which limits store growth and is a natural fit for "self-cleanup".
- **Letta**
  - Apache-2.0. A full agent runtime with editable memory blocks; heavier.
- **Pick:** Mem0 (Python library, can use Ollama for extraction and embeddings) as LOKI's shared memory across harnesses. Add a nightly "consolidate and prune" job run by qwen3.5 9B, which dedupes and expires stale facts.
  - Use Hindsight instead if you want a single container with no config.
  - Effort: M.
  - Note: I did not verify Ollama or MCP support in the sources above; both projects have advertised them in the past.

### 5.2 Voice
- **Chatterbox / Chatterbox Turbo:** MIT, 350M parameters, voice cloning, best-rated open model on TTS Arena; runs on Apple MPS at about 1.1× real-time on an M4. Use for NPC lines and trailer voice-over.
- **Kokoro-82M:** Apache-2.0, 13.8× real-time on the M4 GPU. Use for fast UI and agent narration.
- **Qwen3-TTS:** Apache-2.0, Jan 2026, prompt-directed delivery; slow on the M4, so run it on the PC.
- Source: [yaps.ai licence-checked list](https://www.yaps.ai/blog/best-local-tts-models) (the publisher sells a TTS app).
- **Effort:** S each, through a small local HTTP wrapper.

### 5.3 Browser automation (headless, API-style; not screen control)
- **Playwright MCP** ([microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp))
  - Apache-2.0. Run `npx @playwright/mcp@latest --headless`.
  - Uses accessibility-tree snapshots, so text-only local models can drive it.
  - Use for research such as competitor Steam pages and trends, or filling the owner's **own** dashboards. Not for automated posting (see 1.6).
  - This respects the owner's no-screen-control rule because it never touches their desktop.
  - Effort: S. [morphllm summary](https://www.morphllm.com/playwright-mcp).

## 7. Caveats and open questions
- Last-commit dates were often not visible on GitHub pages because the API was blocked, so "active in 2026" is inferred from dated releases, changelogs and news.
- **License traps for an AGPL app:**
  - Hunyuan3D: Tencent Community License, which excludes the EU, UK and South Korea.
  - Stable Audio and Stable Fast 3D: Stability Community License, under a $1M revenue cap.
  - LTX-2: Community License.
  - Remotion: source-available.
  - FLUX.1-dev weights: non-commercial.
  - OpenShorts `cloud/`: commercial license.
  - Use these only as separately installed tools; never vendor their code into LOKI.
- Unverified this session: the Pixal3D license, the SkinTokens license, whether Hunyuan3D 3.x weights are open, Step1X-3D details, and LTX-2.3 on 8 GB.
- **Automation ToS:** official APIs only for posting, a human approves every publish, Reddit and Steam stay manual, and accounts are labelled as automated where a platform requires it.
