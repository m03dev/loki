# Research, 2026-10-15 (Mohamed's list)

What each project is, and what LOKI took from it.

## OpenMausBot
- github.com/milind-soni/OpenMausBot - TypeScript, Apache-2.0 (an `enterprise/` folder is
  source-available under another licence; never copy from it).
- A local-first desktop app where agents are **chat contacts**: each has a profile, a model, a
  history and its own tools; channels hold group chats with a roster of bots. Runs agents through
  the Claude / Codex / Grok CLIs, an event stream, an MCP server to create bots, inline permission
  cards for shell/file actions, cloud or local VMs for computer use, Composio for Gmail/Slack/etc.
- LOKI already has the same pieces (Agents builder, CLI agents, events, approvals, cua).
  **Idea worth taking next:** show the saved agents in the sidebar as contacts you can open a chat
  with directly, and team channels as group chats. Not built yet.
- Sources: https://osrepos.com/repo/milind-soni-openmausbot ,
  https://www.scriptbyai.com/openmausbot-grok-bot-alternative/

## Artemis
- github.com/nesdeq/artemis - Python, MIT, a Textual terminal assistant (14 commits, new).
- Idea: **independent agents run in parallel before the main model answers**, each decides whether
  it has something useful (memory, web search, URL reader, file reader, RSS news) and adds it to
  the context - "no router, no manager". Encrypted personal memory; litellm for any model.
- For LOKI this maps onto the first layer: run cheap enrichers (memory recall, ReasoningBank,
  URL fetch when a link is pasted) in parallel and add only what is relevant. Not built yet.
- (Other "Artemis" results are unrelated: TurinTech's code optimiser and Kore.ai's enterprise
  agent platform, both commercial.)
- Source: https://github.com/nesdeq/artemis

## Cactus + Needle (phone models)
- github.com/cactus-compute/cactus - on-device inference for phones (Apple, Samsung, Pixel),
  bindings for Swift, Kotlin, Flutter, React Native, Python, Rust; `cactus serve` gives an
  OpenAI-compatible server; models under huggingface.co/Cactus-Compute.
- **Needle**: a tiny distilled tool-calling model (26M in the first release; Needle 2 about 14 MB,
  Needle 3 8-29 MB depending on layers), OpenAI function-calling format. Good for "do this action"
  on a phone; not a chat model.
- Used in the new phone app (`mobile/`, docs/PHONE.md): Needle for quick actions, a 0.6-1.7B chat
  model (Qwen3 0.6B/1.7B, LFM2 350M, Gemma 3 270M, SmolLM2 360M) for conversation, and LOKI on the
  Mac/PC whenever the phone can reach it.
- Sources: https://cdn.jsdelivr.net/gh/cactus-compute/cactus@main/README.md ,
  https://www.mindstudio.ai/blog/cactus-needle-3-on-device-tool-calling-model/ ,
  https://rits.shanghai.nyu.edu/ai/cactus-releases-needle-a-26m-distilled-model-for-on-device-tool-calling

## Roboflow trackers
- PyPI `trackers`, Apache-2.0: SORT, ByteTrack, OC-SORT, BoT-SORT; plugs into any detector via
  `supervision` Detections and `tracker.update(detections)`.
- Added as the optional **vision-track** add-on (RF-DETR Nano detector, Apache-2.0; Ultralytics is
  AGPL so not the default): `tools/setup_extras.py vision`, then "track the cars in clip.mp4".
- Source: https://trackers.roboflow.com/latest/learn/about/ , https://github.com/roboflow/trackers
