# Research, 2026-10-17: new open-source projects that make LOKI better

The owner: "take code from open-source repos to improve LOKI natively - not the ones we have, but
also research for me". Licence decision: LOKI stays private, copy anything, keep each licence
next to the copied code and list it in `docs/THIRD_PARTY.md`.

This list leaves out every project already documented in LOKI (OpenHands, OpenHuman, Scrapling,
browser-use, cua, Crawl4AI, Firecrawl, herdr, Hindsight, Kiln, Remotion, MuMuAINovel, PenEcho,
...; see `docs/THIRD_PARTY.md`, `docs/integrations/INTEGRATION_REGISTRY.md`,
`research-2026-10-15.md`). Stars were read from each GitHub page on 2026-10-17 (rounded); the
GitHub API was not reachable from the session, so "last commit" dates come from shallow clones of the
repos that were ported from.

**Ported in session 27** (code in `engine/`, licences in `engine/licenses/`, 141 offline checks in
`tests/test_research_ports.py`): aider (repo map + SEARCH/REPLACE edits), langgraph-bigtool
(find_tools), instructor (structured output), ReWOO (plan_and_solve), Reflexion (reflect), STORM
(deep_research + web_search), Fooocus (image prompt styles), ACE-Step 1.5 (make_music), Kokoro (speak).

## What was ported, and why it matters for a 7-9B model

- **repo_map** (aider): a local model cannot read a project; grepping blind burns its turns. One call
  shows the important definitions ranked for the request. Without tree-sitter/networkx: `ast` for
  Python, regexes for JS/TS/GDScript/Go/Rust/..., a 40-line PageRank, and two LOKI additions -
  `module.name` references go to `module.py` only, and a file's own copy of a common name
  (`data_dir`, `TIMEOUT_S`) is not a cross-file dependency.
- **apply_edits** (aider): edits as plain text blocks, no JSON escaping of code. Forgiving matching,
  partial success, did-you-mean, CRLF kept, `undo_edit` works on it.
- **find_tools** (bigtool): the 22-tool limit for local models stays, but the model can now reach
  every other tool by describing the need; found tools join its list from the next step (at most 6).
- **extract_structured** (instructor): constrained JSON on local servers, lenient parsing, schema
  validation and re-ask.
- **plan_and_solve** (ReWOO): one plan, tools run without the model, one answer. Read-only tools,
  every call through LOKI's policy (a path outside the workspace is DENIED - tested).
- **reflect** (Reflexion): a failure becomes a lesson in episodic memory; later similar requests get
  it in their memory pack automatically.
- **deep_research / web_search** (STORM): cited reports without any API key.
- **enhance_image_prompt** (Fooocus): 25 named styles (pixel art, cinematic, anime, ...) + expansion;
  the result goes to `generate_media` / the image specialist (that code path is unchanged).
- **make_music** (ACE-Step) and **speak** (Kokoro): local creative output on both machines.
