# Accessibility
<!-- tags: accessibility, a11y, bigger text, font size, high contrast, motion, colour blind, color blind, screen reader, keyboard -->

Open **Settings > General > Language and accessibility**. The settings are saved on this computer and apply at once.

- **Text size** - 100%, 115%, 130% or 150%. Everything in the window grows.
- **High contrast** - black and white with strong outlines and a yellow focus ring.
- **Motion** - *Reduce motion* stops animations and hides the moving 3D world behind the home screen. *Follow this computer's setting* uses your system's "reduce motion" option.
- **Colour-blind-safe colours** - status colours become blue, orange and yellow, always with a symbol (✓, ✕, …) so colour is never the only signal.

The welcome tour has **Bigger text** and **High contrast** buttons on its first page too.

## Screen readers

Every icon button has a name that screen readers announce, the same name its tooltip shows. Dialogs (the welcome tour, the examples, help, Settings) are announced as dialogs, keep the focus inside while open, and give it back when closed.

## Keyboard

Everything works with the keyboard. See **Keyboard shortcuts**.
