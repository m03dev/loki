# Updates
<!-- tags: update, version, new version, upgrade, rollback -->

LOKI keeps itself up to date.

- When a new version is out, a banner says so. Press **Update everything** (or quit and open LOKI again).
- Before switching, LOKI tries the new version in the background. A version that does not start is never used: LOKI stays on the one that works and says why.
- After an update, LOKI keeps the new version only once its window opens properly. If it does not, LOKI goes back to the previous version by itself.
- **Settings > Machines & updates** shows the version you have and every update on this computer.

Installed LOKI with the installer? It updates the same way, from LOKI's release downloads. Your chats, settings and keys are kept across updates.

Turn automatic updates off in **Settings > General** if you prefer.
