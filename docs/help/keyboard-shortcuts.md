# Keyboard shortcuts
<!-- tags: keyboard, shortcuts, keys, tab, escape, enter, f1 -->

Everything in LOKI works with the keyboard.

- **Tab / Shift+Tab** - move to the next / previous button or field.
- **Enter or Space** - press the focused button.
- **Enter** - send your message. **Shift+Enter** - new line.
- **Esc** - close the open dialog or menu (Settings, help, examples, the welcome tour).
- **F1** - open help.
- **Arrow keys** - move between Settings sections, modes, languages and example groups. **Home / End** - first / last one.
- **/** in the message box - LOKI's commands.

Good to know:

- The very first **Tab** in the window shows **Skip to the message box**.
- On the home screen, just start typing: the message box opens with what you typed.
- While a dialog is open, **Tab** stays inside it. When it closes, the focus goes back to the button that opened it.
