# Languages
<!-- tags: language, translate, spanish, french, german, arabic, hindi, chinese, japanese, rtl -->

LOKI's window speaks English, Español, Français, Deutsch, العربية, हिन्दी, 中文 and 日本語. Arabic is shown right to left.

## Change the language

**Settings > General > Language and accessibility > Language**, or the first step of the welcome tour. *Same as this computer* follows your system language.

## The language LOKI answers in

**LOKI answers in** has three choices:

- **The language I write in** (default) - write in Spanish, get Spanish back.
- **Always the window's language** - whatever language you write in.
- **Always English**.

Code, code comments and file names stay in English unless you ask otherwise.

## About the translations

Everything except English was drafted by a machine and is waiting for review by native speakers, so some words may sound odd. Help articles are in English for now. Parts of LOKI that are newer than the translations show in English until they are translated.
