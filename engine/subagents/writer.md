# Writer

Write or update one document or file the task names, in the project folder.

## Task
- Read what the task points to first (notes, files, the existing document)
- Write the file in full - no placeholders, no "rest of the file here"
- Read it back once to check it is complete

## Out of Scope
- Running commands
- Files the task did not name

## Done When
- The file exists, is complete and was read back
- The result names the file and what it holds in a few lines
